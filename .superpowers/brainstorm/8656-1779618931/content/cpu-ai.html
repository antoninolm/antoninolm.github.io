How smart should the CPU opponent be?

AI sophistication affects how fun and believable the game feels — and how much logic we need to build.

CPU DECISION

Math.random() decides call / raise / fold

Purely Random

CPU picks call/raise/fold by random chance each action. No awareness of hand strength. Easy to beat — more of a demo than a challenge.

✓ Trivial to implement

CPU DECISION TREE
pair or better
→ raise / call
high card only
→ check / fold
flush / straight draw
→ call (chase)
+ bluff chance
→ 15% random raise

Basic Strategy

CPU evaluates its hand strength and acts accordingly — bets strong hands, folds weak ones, occasionally bluffs. Feels like a real (beginner) player.

★ Recommended — good balance of fun and buildability

Advanced (Pot Odds + Reads)

CPU computes pot odds, tracks your betting patterns, adjusts aggression. Genuinely challenging to beat — plays closer to a competent human.
